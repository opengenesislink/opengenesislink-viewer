# OpenGenesisLINK Viewer

Native first-party Viewer for the OpenGenesisLINK virtual-world platform.

This repository is intentionally separate from the OpenGenesisLINK Server. The Server is authoritative; the Viewer integrates through the versioned Core HTTP and Scene contracts.

## Integration baseline

- Server baseline: `OpenGenesisLINK Server 1.0.0-alpha.1`
- Release discovery: `ogl-release-v1`
- Viewer bootstrap: `ogl-viewer-bootstrap-v1`
- Scene application contract: `scene-v2`
- Scene transport: OGL1 protocol 1

Development starts from the canonical Viewer handover and the matching server-side contract documents.

## Status

Repository bootstrap in progress. Rendering is deliberately not coupled into the contract/network foundation yet.
