# OpenGenesisLINK Viewer branding

The files in this directory are build-ready derivatives of the official
OpenGenesisLINK Viewer application logo supplied by the project.

No replacement artwork is generated by the build system.

- `opengenesislink-viewer.png`: 64x64 PNG for Linux desktop/icon installation.
- `opengenesislink-viewer.ico`: multi-size Windows executable icon
  (16, 24, 32, 48 and 64 px).

The original high-resolution project artwork remains the branding source.
Larger packaging assets can be added from that same source without redesigning
the logo.
